# Optional dependencies to ENABLE the semantic-search / RAG layer.
#
# Kept separate from requirements.txt on purpose, but NOT for the reason this file
# used to give. Measured on Python 3.11:
#
#     app at rest ..............  70 MB
#     fastembed + model ........ 155 MB
#     -------------------------------
#     total .................... 225 MB   (Render free tier: 512 MB)
#
# So it fits, with roughly 290MB to spare. The old claim that this would OOM on a
# 512MB host was wrong.
#
# The real cost is cold starts. The ~130MB model is fetched on first use, and on a
# tier with an ephemeral filesystem that spins down when idle, that download repeats
# every wake — adding ~15s on top of an already slow start. That, not memory, is the
# reason to think twice on a free tier.
#
# Without this, semantic matching becomes literal matching: search and Ask still work,
# passages are still retrieved from the document text, and nothing crashes.
#
# The app degrades gracefully without this: if fastembed isn't installed, semantic
# search + "Ask Your Records" fall back to keyword search, and nothing crashes.
#
# Install ONLY on a host with enough RAM (Oracle / Hugging Face Spaces / a paid
# tier), on top of the base requirements:
#     pip install -r requirements.txt -r requirements-rag.txt
# Then run backend/database/migrations/001_semantic_search.sql in Supabase.

fastembed==0.5.1
